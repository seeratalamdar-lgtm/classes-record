
COMPLETE ACADTRACK KNOWLEDGE BASE
==================================

HOME PAGE (schoolcollege.online):
Buttons: My Schedules | Faculty Sign In | Student Sign In | Account & Finance | Admin Panel | Tutorial | Contact Us | Public Schedules
- My Schedules: Admin creates/manages schedules. Requires username+password login.
- Faculty Sign In: Faculty marks attendance P/A/L, enters exam marks, uploads notes, views schedule
- Student Sign In: Student views attendance%, marks, fee status, downloads notes
- Account & Finance: Manages fee payments, salaries, payment summaries. Requires Finance PIN
- Admin Panel: Super admin manages all users, passwords, locks accounts, views CSV of all users
- Tutorial: PDF guide with 5 topics and examples. Downloadable.
- Contact Us: Alamdar Hussain, Islamabad. Email/WhatsApp/Phone available.
- Public Schedules: Schedules made public by admins, viewable without login

MY SCHEDULES SCREEN:
Buttons: Sign In | Register | Change Password | Finance PIN | Logout | New Schedule | Delete Schedule | Public toggle
- Admin logs in with username+password
- Creates schedules with: Name, Start Date, End Date, Start Time, End Time, Lecture Duration (30/45/60/90 min), Break Time, Active Days (Mon-Sun)
- Each schedule card navigates to Schedule Dashboard
- Finance PIN: 4+ character PIN for Finance access

SCHEDULE DASHBOARD:
Buttons: Weekly Schedule | New Entry | Teaching Summary | Meeting Availability | Gazetted Holidays | Attendance | HR Personnel | Exam Marks
- Back button (top left) | Home button (top right)
- All features are for that specific schedule only

WEEKLY SCHEDULE SCREEN:
Buttons: Back | Download (PDF) | Export CSV | Override | Import Day | Edit | Filter by Class | Filter by Faculty | Filter by Location
- Grid view: Time rows × Day columns
- Each cell shows: Subject, Class, Faculty, Room, Lec/Lab tag
- Download: Generates PDF of full timetable
- Export CSV: Downloads all schedule slots as CSV (Faculty, Subject, Class, Day, Time, EndTime, Location, LecLab)
- Override: Upload new CSV to replace entire schedule
- Import Day: Bulk import all entries for a specific day
- Edit mode: Click cells to copy/paste/delete entries
- Filters: Narrow grid by Class, Faculty, or Location

NEW ENTRY SCREEN (Missed/Makeup/Late):
Buttons: Back | Home | Import Day | All Entries | Entry Type (Missed/Late/Makeup) | Faculty | Subject | Class | Date | End Time | Location | Save Entry
- Entry Types: Missed (faculty didnt conduct), Late (conducted late), Makeup (extra session)
- All Entries button opens modal with 2 tabs:
  TAB 1 - Saved Entries: List of all entries. Buttons: Export CSV, Override
    Export CSV downloads: Faculty, Subject, Class, Date, Type, Time, EndTime, Location, Remarks
  TAB 2 - Add Entry: Manual form to add entry
- Import Day: Auto-import all scheduled classes for a day as Missed/Makeup

TEACHING SUMMARY SCREEN:
Buttons: Back | Home | Download (PDF) | Start Date filter | End Date filter | Apply Date Filter | Export CSV
- Shows per-faculty row: Faculty, Subject, Class, Dept, TBC, Missed, Makeup, Late, Grand Total, Status
- Status: On Track (Grand Total >= TBC), Deficit (below), Surplus (above)
- TBC = To Be Conducted (calculated from schedule dates minus holidays)
- Grand Total = TBC - Missed + Makeup + Late
- Missed/Makeup/Late dates shown as colored badges
- Download generates PDF report
- Export CSV downloads the summary data

MEETING AVAILABILITY SCREEN:
Buttons: Back | Home | Download | Date picker | Start Time | End Time | Faculty filter | Generate Report | Clear all
- Enter date + time range → shows Free and Busy faculty lists
- Free = faculty with no class at that time
- Busy = faculty with class at that time
- Department Breakdown shows count per dept
- Download generates PDF of Free/Busy lists

GAZETTED HOLIDAYS SCREEN:
Buttons: Back | Home | Add Holiday | Single Day | Date Range | Select Date | End Date | Delete
- Add single day or date range as holiday
- Holidays auto-excluded from TBC count in Teaching Summary
- Shows list of all holidays with delete option
- Holiday types: National holidays, Eid, etc.

ATTENDANCE SCREEN:
Buttons: Back | Home | Search | Select Date | Load | All Present | Save | Mark P/A/L per student | Lock attendance
- Select class → select date → mark P/A/L for each student
- P = Present, A = Absent, L = Leave
- All Present: marks all students present in one click
- Attendance locked after certain time (admin configurable)
- Roster tab: View attendance summary per student
- Students tab: Manage enrolled students

HR PERSONNEL SCREEN:
Buttons: Back | HR Personnel | Students tab | Faculty tab | Staff tab | Open Students Screen | Open Faculty Access | Open Student Access | New [tab] Join | Save | Delete
- Students tab: Links to Students screen for enrollment
- Faculty tab: Links to Faculty Credentials screen
- Staff tab: Add/manage support staff with salary info
- Add join/leave records for personnel

FACULTY CREDENTIALS SCREEN:
Buttons: Back | Home | Faculty Access | Generate All | Download Excel | Save | Regenerate | Delete | View Details
- Lists all faculty with username, password, email
- Generate All: Creates credentials for all faculty
- Download Excel: Downloads all credentials as Excel file
- Individual faculty: View/edit username, password, email, classes
- Credentials used for Faculty Sign In portal

STUDENT CREDENTIALS SCREEN:
Buttons: Back | Home | Student Access | Generate All | Download Excel | Save | Regenerate | Delete
- Same as Faculty Credentials but for students
- Downloads student login credentials as Excel

STUDENTS SCREEN:
Buttons: Back | Students | Summary tab | Enroll tab | Bulk Upload (Excel) | Del All | Sample | Remove Student
- Summary: Total students per class, enrollment dates
- Enroll: Add students one by one (Roll No, Name, Email)
- Bulk Upload: Upload Excel file with columns: Reg No, Student Name, Email, WhatsApp
- Sample: Download sample Excel template
- Del All: Remove all students from a class

EXAM MARKS SCREEN:
Buttons: Back | Exam Component Weights | Save Weights | Bulk Upload Marks (Excel) | Template | Save marks | Search student
- Components: Quiz, Assignment, Mid, Final (weights must total 100%)
- Save Weights: Saves percentage weights per component
- Enter marks per student per component
- Bulk Upload: Upload Excel with columns: Reg No, Quiz, Assignment, Mid, Final
- Template: Download blank template
- Search: Find student marks by name/roll no

FACULTY PORTAL (/faculty-portal):
Buttons: Home | Sign Out | Attendance | Exam Marks | My Schedule | My Notes | Change Password
- Login with username+password (generated by Admin)
- Attendance: Same date-based marking as admin attendance
- Exam Marks: Enter quiz/mid/final marks for assigned classes
- My Schedule: View personal weekly timetable (read-only)
- My Notes: Upload PDF/Word/Excel/images (max 10MB per file) for students
- Change Password: Faculty changes own password

STUDENT PORTAL (/student-portal):
Buttons: Home | Sign Out | Weekly Schedule | Faculty Notes | Change Password
- Login with username+password (generated by Admin)
- Views attendance percentage per subject
- Views exam marks (Quiz, Assignment, Mid, Final, Total)
- Views fee payment status
- Downloads notes uploaded by faculty
- Views weekly timetable (read-only)

FINANCE SCREEN:
Buttons: Set rates | Bulk Upload Rates | Template | Select schedule | Month picker | Payment history | Due/Paid/Balance
- Manage salary rates for faculty and staff
- Record fee payments for students
- View payment summaries per person per month
- Total Due, Total Paid, Balance shown
- Bulk upload rates via Excel

ADMIN PANEL:
Buttons: Enter admin credentials | Enter OTP | User list | Activate | Lock/Unlock | Password | Delete | Set Expiry
- Super admin login with username+OTP
- View all registered users with schedule count
- Activate new accounts
- Lock/Unlock accounts
- Reset passwords
- Set account expiry dates
- Download CSV of all users

SCHEDULE GENERATOR (AI):
Buttons: Back | Upload Draft CSV | Download Draft | Generate Schedule | Import to Schedule
- Upload CSV with columns: Subject Code, Subjects, Department, Instructor Name with Sections, Regular/Elective, Class, Credit Hrs
- Credit Hrs format: "3+1" = 3 lectures + 1 lab per week
- Instructor sections in brackets: "Dr. Ali (ABC)" = sections A, B, C
- AI generates conflict-free timetable respecting break times
- Download Draft: Preview generated schedule as CSV
- Import: Save generated schedule to database

FILE FORMATS:
Schedule CSV upload: Faculty, Subject, Class, Day, Time, EndTime, Location, LecLab
Saved Entries CSV: Faculty, Subject, Class, Date, Type(Missed/Makeup/Late), Time, EndTime, Location, Remarks
Student bulk upload: Reg No, Student Name, Email, WhatsApp
Faculty credentials Excel: Faculty Name, Username, Password, Email
Draft schedule CSV: Subject Code, Subjects, Department, Instructor Name with Sections, Regular/Elective, Class, Credit Hrs
Exam marks Excel: Reg No, Student Name, Quiz, Assignment, Mid, Final
Attendance roster: Class, Reg No, Name, dates as columns, P/A/L values

API ENDPOINTS USED BY BUTTONS:
GET /api/schedule?scheduleId=X → Weekly Schedule data
GET /api/summary?scheduleId=X → Teaching Summary
GET /api/schedule/entries?scheduleId=X → All Entries (Missed/Makeup/Late)
GET /api/holidays?scheduleId=X → Gazetted Holidays
GET /api/meeting → Meeting Availability
GET /api/attendance/roster → Attendance roster
GET /api/attendance/students → Student list
GET /api/faculty-access → Faculty credentials
GET /api/student-access → Student credentials
POST /api/import/schedule → Import schedule CSV
POST /api/entries → Save new entry
POST /api/attendance/mark → Mark attendance
